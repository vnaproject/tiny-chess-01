A chess engine in 3,757 bytes of Python: 0x88 board, negamax alpha-beta with PVS, null-move pruning, LMR, check extensions, quiescence search, transposition table, killer + history move ordering, and incremental material + piece-square evaluation — all under a fixed 150,000-node budget per move, so play is fully deterministic.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
